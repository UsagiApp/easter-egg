# 0.0.3

This build contains special events, including the ability to dynamically change the app icon when triggered.

## Requirements

- Android Studio or IntelliJ IDEA (Community Edition is enough)
- Android SDK 35 or later (if not using IDE)
- Java 11 or later is required
